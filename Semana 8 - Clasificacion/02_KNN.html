Intuición de KNN

El algoritmo K-Nearest Neighbors (K-Vecinos Más Cercanos) es uno de los métodos más intuitivos. Funciona bajo el principio de que los objetos similares tienden a estar cerca unos de otros.

Cuando llega un dato nuevo que no sabemos a qué clase pertenece, el algoritmo hace lo siguiente:

  1. Mide la distancia entre el nuevo punto y todos los puntos de entrenamiento.
  2. Selecciona los $K$ puntos más cercanos (vecinos).
  3. La clase del nuevo punto se decide por votación mayoritaria de esos $K$ vecinos.
📏

Matemáticas de Distancia

Para saber quiénes son los vecinos más cercanos, el algoritmo calcula distancias. La métrica más común por defecto en Scikit-Learn es la Distancia Euclidiana.

En un espacio de dos dimensiones (dos características, $X_1$ y $X_2$), la distancia $d$ entre dos puntos $p$ y $q$ se calcula mediante el teorema de Pitágoras:

$$d(p, q) = \sqrt{(q_1 - p_1)^2 + (q_2 - p_2)^2}$$
Al calcular distancias geométricas, las escalas de las variables son críticas. Si una característica está en miles y otra en decimales, la mayor dominará la distancia. ¡Por eso estandarizar es obligatorio en KNN!
💻

Implementación en Python

Aplicaremos KNN en Scikit-Learn. Simularemos un conjunto de datos simple y utilizaremos el escalado necesario.

import numpy as np
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

# Datos simulados: [Edad, Salario (miles)]
X_train = np.array([[25, 40], [30, 60], [45, 80], [50, 120]])
y_train = np.array([0, 0, 1, 1]) # 0: Rechazado, 1: Aprobado (Préstamo)

# Estandarizar
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)

# Instanciar el modelo con K=3
knn = KNeighborsClassifier(n_neighbors=3)
knn.fit(X_scaled, y_train)

# Nuevo cliente: Edad 35, Salario 75
nuevo_cliente = scaler.transform([[35, 75]])
prediccion = knn.predict(nuevo_cliente)
print("Clase predicha:", prediccion)
🎛️

La elección de K

El hiperparámetro $K$ (el número de vecinos a considerar) define drásticamente el comportamiento de la clasificación.

  • Si $K$ es muy bajo (ej. $K=1$): El modelo es muy sensible al ruido (Sobreajuste). Trazará fronteras complejas buscando complacer a cada punto atípico.
  • Si $K$ es muy alto: La votación será dominada siempre por la clase más frecuente en general (Subajuste).
Suele recomendarse usar valores impares para $K$ (ej. 3, 5, 7) para evitar "empates" al momento de la votación mayoritaria entre dos clases.
