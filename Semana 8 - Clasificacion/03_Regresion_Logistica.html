Regresión Logística

Usando probabilidades para decidir el lado correcto de la frontera

🤔

¿Qué es a pesar de su nombre?

El nombre Regresión Logística puede ser engañoso. Aunque tiene la palabra "Regresión", es en realidad un poderoso algoritmo lineal utilizado en problemas de Clasificación.

Calcula la ecuación lineal básica ($y = \beta_0 + \beta_1X$), pero en lugar de generar un número infinito (como el precio de una casa), pasa ese resultado por una función especial para devolver una probabilidad entre 0 y 1.

📈

La Función Sigmoide

La magia detrás del algoritmo reside en la función Sigmoide (también llamada función logística). Dibuja una curva en forma de "S".

$$p(x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1x)}}$$

El modelo evalúa las características y escupe una probabilidad, por ejemplo: $0.85$. Por defecto, si la probabilidad es $>= 0.5$, lo clasifica como Clase 1 (Ej. Spam). Si es $< 0.5$, lo clasifica como Clase 0.

💻

Implementación en Python

Es muy similar a usar la Regresión Lineal regular de Scikit-Learn.

import numpy as np
from sklearn.linear_model import LogisticRegression

# Simulamos datos (1 variable predictora)
X_train = np.array([[10], [15], [30], [50]]) # Horas de estudio
y_train = np.array([0, 0, 1, 1]) # 0 = Reprobado, 1 = Aprobado

# Instanciar y Entrenar
modelo_log = LogisticRegression()
modelo_log.fit(X_train, y_train)

# Predecir sobre 25 horas y 40 horas
X_nuevo = np.array([[25], [40]])
predicciones = modelo_log.predict(X_nuevo)
print("Predicciones (0 o 1):", predicciones)
🔮

Interpretación de Probabilidades

Una gran ventaja de este algoritmo es que no solo entrega un diagnóstico final (0 o 1), sino que podemos consultar su nivel de seguridad usando el método .predict_proba().

# Consultar la probabilidad calculada por la curva sigmoide
probabilidades = modelo_log.predict_proba(X_nuevo)
print("Probabilidad de [Clase 0, Clase 1]:\n", probabilidades)

Salida esperada (Aproximada):

Probabilidad de [Clase 0, Clase 1]:
[[0.62  0.38]
 [0.15  0.85]]
Para el primer alumno (25h), el modelo cree que hay un 62% de probabilidad de reprobar (0) frente a 38% de aprobar (1). Por tanto, la clase final será 0.
🎓

Resumen: Regresión Logística

📉 Lineal pero Clasificador
Calcula una frontera de decisión lineal.
📈 Sigmoide
Aplica la función matemática que "aplasta" valores a $0 \leftrightarrow 1$.
🔮 Probabilidades
.predict_proba() entrega certezas porcentuales.
⚙️ Scikit-Learn
sklearn.linear_model.LogisticRegression
