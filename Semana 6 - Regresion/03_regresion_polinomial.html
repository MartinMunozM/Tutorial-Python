Tutorial: Regresión Polinomial

Descubre cómo moldear predicciones para datos que no siguen una línea recta

🎢

¿Qué es la Regresión Polinomial?

A menudo nos encontramos con que la relación entre nuestras variables no es una simple línea recta. La vida real está llena de curvas: crecimiento poblacional, trayectorias físicas o curvas de oferta y demanda.

La Regresión Polinomial adapta nuestro modelo lineal para que pueda curvarse añadiendo potencias adicionales (grados) de nuestra variable predictora $x$. Un modelo polinomial de grado 2 (cuadrático) se ve así:

$$y = \beta_0 + \beta_1x + \beta_2x^2$$

Si aumentamos el grado a 3 (cúbico), la fórmula se expande:

$$y = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$$
¡Sorpresa! Aunque produce una curva, matemáticamente sigue siendo una forma de Regresión Lineal Múltiple. Simplemente tratamos a $x^2$ y $x^3$ como si fueran nuevas características ($x_2$ y $x_3$).
🧬

Datos con Tendencias Curvas

Para ilustrar la necesidad de la regresión polinomial, generaremos datos que siguen claramente una trayectoria cuadrática y veremos cómo falla una línea recta tradicional.

import numpy as np
import matplotlib.pyplot as plt

# Generamos datos no lineales (una parábola con ruido)
np.random.seed(42)
m = 100
X = 6 * np.random.rand(m, 1) - 3
y = 0.5 * X**2 + X + 2 + np.random.randn(m, 1)

# Mostramos los primeros valores
print("X[:3]:\n", X[:3])
print("y[:3]:\n", y[:3])

Salida esperada:

X[:3]:
 [[-0.75275929]
 [ 2.70428584]
 [ 1.39196365]]
y[:3]:
 [[ 1.61781254]
 [ 8.16912384]
 [ 4.70889271]]
Si intentas usar `LinearRegression()` básica en estos datos, la línea recta resultante cruzará la curva torpemente, incurriendo en un Error Cuadrático Medio altísimo en los extremos y en el centro.
⚡

Ingeniería de Features: PolynomialFeatures

Para ajustar una curva, primero necesitamos crear artificialmente las columnas de $x^2$. Scikit-Learn proporciona la herramienta perfecta: PolynomialFeatures.

Esta clase toma nuestra característica original $x$ y añade nuevas columnas conteniendo $x^2, x^3$, etc., hasta el grado que le indiquemos.

from sklearn.preprocessing import PolynomialFeatures

# 1. Instanciamos el transformador (grado 2)
poly_features = PolynomialFeatures(degree=2, include_bias=False)

# 2. Transformamos nuestra X original
X_poly = poly_features.fit_transform(X)

# Veamos cómo cambió la primera observación
print("X original (x):", X[0])
print("X polinomial (x, x^2):", X_poly[0])

Salida esperada:

X original (x): [-0.75275929]
X polinomial (x, x^2): [-0.75275929  0.56664654]

Ahora nuestra matriz X_poly contiene tanto el valor original como su cuadrado, dejándola lista para alimentar a un modelo de regresión estándar.

📉

Ajustando y Visualizando la Curva

Al tener nuestra matriz transformada, podemos utilizar exactamente la misma clase LinearRegression() de los módulos anteriores. El modelo "cree" que está haciendo regresión múltiple, pero el resultado en la gráfica será una parábola suave.

from sklearn.linear_model import LinearRegression

# Entrenamos la Regresión Lineal sobre las features polinomiales
lin_reg = LinearRegression()
lin_reg.fit(X_poly, y)

# Para graficar una curva suave, generamos puntos intermedios
X_new = np.linspace(-3, 3, 100).reshape(100, 1)
X_new_poly = poly_features.transform(X_new)
y_new = lin_reg.predict(X_new_poly)

# Graficar resultados
plt.plot(X, y, "b.", label="Datos Originales")
plt.plot(X_new, y_new, "r-", linewidth=2, label="Predicción (Grado 2)")
plt.xlabel("$x$")
plt.ylabel("$y$")
plt.legend()
plt.show()

En el gráfico, observarás que la línea roja ya no es rígida, sino que se dobla conformando un tazón, trazando exquisitamente el comportamiento real subyacente de nuestros datos.

🚨

El Peligro del Sobreajuste (Overfitting)

Si usar grado 2 nos dio una curva, ¿por qué no usar grado 20 o 300 para que la línea toque perfectamente todos los puntos de entrenamiento?

Al utilizar un grado polinomial extremadamente alto, el modelo dejará de buscar el patrón general y comenzará a "memorizar" el ruido y las anomalías de los datos. A este fenómeno lo llamamos Sobreajuste u Overfitting.

Consecuencias de un grado muy elevado:

  • Alta Varianza: La curva saltará salvajemente hacia arriba y hacia abajo para tratar de conectar cada punto aislado.
  • Fracaso en la Predicción: Aunque tu $MSE$ en el entrenamiento será cercano a 0, el modelo predecirá atrocidades (valores absurdamente altos o bajos) al enfrentarse a nuevos datos en el conjunto de Test.
  • Explosión Dimensional: Elevar variables múltiples a grados altos escala el número de columnas de forma combinatoria, consumiendo drásticamente la memoria computacional.

Recomendaciones prácticas:

  1. Aplica validación cruzada y mantén el grado ($degree$) lo más bajo posible (casi siempre 2 o 3 es suficiente).
  2. Utiliza técnicas de regularización (como regresión Ridge o Lasso) para penalizar y mantener los coeficientes $\beta$ bajo control.
  3. Vigila siempre la diferencia entre el error de entrenamiento y el error de prueba.

Resumen: Regresión Polinomial

Flexibilizamos nuestro modelo lineal para abrazar la complejidad no-lineal de la naturaleza.

🎢 No-Linealidad
Modela curvas utilizando combinaciones polinomiales de las variables existentes.
⚡ PolynomialFeatures
Transforma matrices 1D en matrices N-D agregando $x^2, x^3 \dots$
🧠 Ilusión Lineal
Se resuelve internamente con LinearRegression bajo el velo Múltiple.
🚨 Sobreajuste
Grados excesivos generan curvas inestables que fracasan prediciendo datos nuevos.
