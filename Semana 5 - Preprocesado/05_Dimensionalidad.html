¿Qué es la Reducción de Dimensionalidad?

Imagina que tienes un conjunto de datos con cientos o miles de columnas (características o "dimensiones"). Analizar, visualizar y modelar con tantos datos puede ser computacionalmente costoso y propenso al sobreajuste ("la maldición de la dimensionalidad").

La Reducción de Dimensionalidad es el proceso de reducir el número de variables en un conjunto de datos, conservando la mayor cantidad de información "importante" posible.

Beneficios:

  • Visualización: Nos permite visualizar datos de alta dimensionalidad en 2D o 3D.
  • Eficiencia: Reduce el tiempo de entrenamiento y los requerimientos de almacenamiento.
  • Rendimiento del Modelo: Puede mejorar el rendimiento de algunos modelos al eliminar ruido y redundancia.

La técnica más popular para la reducción de dimensionalidad lineal es el Análisis de Componentes Principales (PCA).

PCA encuentra nuevas variables (componentes principales) que son combinaciones lineales de las originales y que capturan la máxima varianza posible en los datos.
🗺️

Análisis de Componentes Principales (PCA)

El Análisis de Componentes Principales (PCA) es un algoritmo que transforma tus datos en un nuevo sistema de coordenadas. En este nuevo sistema:

  • El primer componente principal (PC1) es el eje que captura la mayor varianza (dispersión) en los datos.
  • El segundo componente principal (PC2) es el eje, ortogonal (perpendicular) al primero, que captura la mayor parte de la varianza restante.
  • Y así sucesivamente...

Al quedarnos solo con los primeros componentes (ej. PC1 y PC2), podemos representar la mayor parte de la estructura de nuestros datos en un espacio de menor dimensión.

¡Importante! PCA es muy sensible a la escala de las variables. Antes de aplicar PCA, es esencial estandarizar tus datos (media 0 y desviación estándar 1) para que todas las variables contribuyan por igual. 
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.datasets import load_iris # Un dataset clásico

# 1. Cargar y preparar datos de ejemplo
iris = load_iris()
X = iris.data
y = iris.target
print(f"Forma original de los datos: {X.shape}") # (150 muestras, 4 características)

# 2. Estandarizar los datos
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. Aplicar PCA para reducir a 2 dimensiones
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
print(f"Forma de los datos después de PCA: {X_pca.shape}")

Salida esperada:

Forma original de los datos: (150, 4)
Forma de los datos después de PCA: (150, 2)

Hemos reducido con éxito nuestras 4 características a 2 componentes principales.

🎨

Visualización de Datos Reducidos

El principal beneficio de reducir a 2 o 3 dimensiones es que podemos visualizar los datos. Un gráfico de dispersión (scatterplot) es ideal para esto.

Podemos graficar el primer componente principal (PC1) en el eje X y el segundo (PC2) en el eje Y. Si tenemos etiquetas (como en el dataset Iris), podemos colorear los puntos según su clase para ver si PCA ha logrado separar los grupos.

import matplotlib.pyplot as plt
import seaborn as sns

# Crear un DataFrame con los resultados de PCA para facilitar la visualización
df_pca = pd.DataFrame(data=X_pca, columns=['PC1', 'PC2'])
df_pca['Especie'] = y # Añadir la variable objetivo (la especie de flor)

# Mapear los números de especie a nombres para la leyenda
df_pca['Especie'] = df_pca['Especie'].map({0: 'Setosa', 1: 'Versicolor', 2: 'Virginica'})

# Crear el gráfico de dispersión
plt.figure(figsize=(8, 6))
sns.scatterplot(x='PC1', y='PC2', hue='Especie', data=df_pca)
plt.title('Visualización PCA del Dataset Iris')
plt.show()

¿Qué veríamos?

Un gráfico 2D donde cada punto es una flor. Los puntos estarían coloreados según su especie. Idealmente, veríamos que los puntos de la misma especie están agrupados, lo que indica que los 2 componentes principales han capturado bien la estructura que separa las clases. Para el dataset Iris, la especie 'Setosa' aparecería claramente separada de las otras dos.

Interpretación de Componentes

Una vez aplicado PCA, es importante saber cuánta información hemos retenido. El objeto PCA de Scikit-learn tiene atributos útiles para esto:

  • .explained_variance_ratio_: Un array que muestra el porcentaje de varianza explicado por cada componente.
  • .components_: Muestra cómo cada componente principal está compuesto por las características originales. Los valores más altos (en magnitud) indican qué características originales son más importantes para ese componente.
# Usando el objeto 'pca' del paso 2
print("Varianza explicada por cada componente:")
print(pca.explained_variance_ratio_)

total_varianza = np.sum(pca.explained_variance_ratio_)
print(f"\nVarianza total explicada por los 2 componentes: {total_varianza:.2f}")

print("\nComposición de los componentes:")
print("PC1:", pca.components_[0])
print("PC2:", pca.components_[1])

Salida esperada (aproximada):

Varianza explicada por cada componente:
[0.72962445 0.22850762]

Varianza total explicada por los 2 componentes: 0.96

Composición de los componentes:
PC1: [ 0.521 -0.269  0.58   0.564]
PC2: [0.377  0.923  0.024  0.066]

Interpretación:

  • El primer componente (PC1) explica aproximadamente el 73% de la varianza en los datos.
  • El segundo componente (PC2) explica otro 23%.
  • Juntos, los dos componentes capturan casi el 96% de la información original, ¡usando solo la mitad de las dimensiones!

Resumen: Reducción de Dimensionalidad

Simplificar tus datos es una técnica avanzada pero muy poderosa.

📉 Objetivo
Reducir el número de variables (features) conservando la información.
🗺️ PCA
Análisis de Componentes Principales. Técnica lineal más común.
⚠️ Requisito Previo
¡Estandarizar los datos! (StandardScaler)
🎨 Visualización
Permite graficar datos de alta dimensionalidad en 2D o 3D.
🧠 Interpretación
explained_variance_ratio_ nos dice cuánta información retiene cada componente.
⚙️ Scikit-learn
La librería clave: sklearn.decomposition.PCA

PCA y otras técnicas de reducción de dimensionalidad son herramientas clave en el preprocesado para machine learning y la visualización de datos complejos.
