Manejo de Valores Nulos (NaN)

La limpieza de datos comienza con el manejo de valores faltantes (NaN). Como vimos en la introducción a Pandas, las dos estrategias principales son eliminar o imputar (rellenar).

Detección: Usa df.isnull().sum() para obtener un conteo rápido de nulos por columna.

Eliminación (.dropna()): Ideal si los datos faltantes son pocos y su eliminación no sesga el conjunto de datos.

import pandas as pd
import numpy as np

data = {'Producto': ['A', 'B', 'C', 'D'],
        'Precio': [100, np.nan, 120, 90],
        'Stock': [50, 20, 0, np.nan]}
df = pd.DataFrame(data)
print("DataFrame original:\n", df, "\n")

# Eliminar filas con cualquier valor nulo
df_sin_nulos = df.dropna()
print("Después de dropna():\n", df_sin_nulos)

Salida esperada:

DataFrame original:
  Producto  Precio  Stock
0        A   100.0   50.0
1        B     NaN   20.0
2        C   120.0    0.0
3        D    90.0    NaN 

Después de dropna():
  Producto  Precio  Stock
0        A   100.0   50.0
2        C   120.0    0.0

Imputación (.fillna()): Preferible cuando perder datos es costoso. Se puede rellenar con la media, mediana (más robusta a outliers), o la moda (valor más frecuente).

# Calcular la media de 'Precio' para imputar
media_precio = df['Precio'].mean()
df_relleno = df.copy() # Creamos una copia para no modificar el original
df_relleno['Precio'] = df_relleno['Precio'].fillna(media_precio)
print("\nDataFrame con 'Precio' rellenado con la media:\n", df_relleno)

Salida esperada:

DataFrame con 'Precio' rellenado con la media:
  Producto      Precio  Stock
0        A  100.000000   50.0
1        B  103.333333   20.0
2        C  120.000000    0.0
3        D   90.000000    NaN

Manejo de Filas Duplicadas

Las filas duplicadas pueden sesgar tus análisis, especialmente los conteos y las estadísticas. Es importante identificarlas y decidir cómo tratarlas.

Detección (.duplicated()): Identifica qué filas son duplicadas.

Eliminación (.drop_duplicates()): Elimina las filas duplicadas.

import pandas as pd
data = {'ID_Cliente': [101, 102, 101, 103, 102],
        'Producto': ['A', 'B', 'A', 'C', 'B']}
df = pd.DataFrame(data)
print("DataFrame original:\n", df, "\n")

# Identificar filas completamente duplicadas (marcando la 2da aparición en adelante)
mascara_duplicados = df.duplicated()
print("Máscara de duplicados:\n", mascara_duplicados, "\n")

# Eliminar duplicados, manteniendo la primera aparición (keep='first' es el default)
df_sin_dups = df.drop_duplicates()
print("DataFrame sin duplicados:\n", df_sin_dups)

Salida esperada:

DataFrame original:
   ID_Cliente Producto
0         101        A
1         102        B
2         101        A  <-- Duplicado de la fila 0
3         103        C
4         102        B  <-- Duplicado de la fila 1

Máscara de duplicados:
0    False
1    False
2     True
3    False
4     True
dtype: bool 

DataFrame sin duplicados:
   ID_Cliente Producto
0         101        A
1         102        B
3         103        C

Corrección de Tipos de Datos (.astype())

A menudo, los datos se cargan con tipos incorrectos (ej. números como texto, fechas como texto). Corregir los tipos de datos es esencial para realizar operaciones correctas y optimizar el uso de memoria.

El método .astype() es la herramienta principal para esta tarea.

import pandas as pd
data = {'ID': [1, 2, 3],
        'Ventas_str': ['150.5', '200', '99.9'],
        'Fecha_str': ['2023-01-10', '2023-02-15', '2023-03-20']}
df = pd.DataFrame(data)
print("Tipos de datos originales:")
print(df.dtypes, "\n")

# Corregir tipos
df['Ventas_float'] = df['Ventas_str'].astype('float')
df['Fecha_dt'] = pd.to_datetime(df['Fecha_str'])

print("Tipos de datos corregidos:")
print(df.dtypes)

Salida esperada:

Tipos de datos originales:
ID             int64
Ventas_str    object
Fecha_str     object
dtype: object 

Tipos de datos corregidos:
ID                       int64
Ventas_str              object
Fecha_str               object
Ventas_float           float64
Fecha_dt        datetime64[ns]
dtype: object
Para fechas, es preferible usar pd.to_datetime() en lugar de .astype('datetime64[ns]'), ya que es más flexible y puede inferir una mayor variedad de formatos de fecha.

Datos Inconsistentes y Ruidosos

La "suciedad" en los datos no se limita a nulos o duplicados. A menudo encontrarás inconsistencias que requieren un tratamiento más específico.

Ejemplos comunes y soluciones:

  • Inconsistencia en mayúsculas/minúsculas: Usa los métodos de string .str.lower(), .str.upper(), o .str.title().
  • Espacios en blanco extra: Usa .str.strip() para eliminarlos al principio y al final.
  • Errores de escritura o categorías inconsistentes: Usa .replace() para estandarizar valores.
  • Valores extraños: A veces, los valores faltantes se codifican como '-', 'N/A', o 999. Usa .replace() para convertirlos a np.nan antes de tratarlos.
import pandas as pd
import numpy as np
data = {'Pais': [' Mexico ', 'colombia', 'Mexico', 'peru'],
        'Puntuacion': [8, 9, 8, -99]} # -99 representa un nulo
df = pd.DataFrame(data)
print("DataFrame ruidoso:\n", df, "\n")

# 1. Corregir valores extraños a NaN
df['Puntuacion'] = df['Puntuacion'].replace(-99, np.nan)

# 2. Corregir inconsistencias de texto
df['Pais'] = df['Pais'].str.strip().str.title() # .str permite usar métodos de string

print("DataFrame limpio:\n", df)

Salida esperada:

DataFrame ruidoso:
         Pais  Puntuacion
0   Mexico           8
1  colombia          9
2    Mexico           8
3      peru         -99 

DataFrame limpio:
       Pais  Puntuacion
0    Mexico         8.0
1  Colombia         9.0
2    Mexico         8.0
3      Peru         NaN

Resumen: Limpieza Avanzada de Datos

Un conjunto de datos limpio es la base de un buen análisis.

💧 Manejo de Nulos
.isnull() (detectar) .dropna() (eliminar) .fillna() (imputar)
👯 Manejo de Duplicados
.duplicated() (detectar) .drop_duplicates() (eliminar)
🔄 Tipos de Datos
.astype() para corregir. pd.to_datetime() para fechas.
✨ Datos Ruidosos
.str (para texto) .replace() (para estandarizar)

Estas técnicas te ayudarán a transformar datos "sucios" del mundo real en conjuntos de datos listos para el análisis y modelado.
