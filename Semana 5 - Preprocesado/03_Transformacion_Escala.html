¿Por Qué Transformar y Escalar?

Una vez que tus datos están limpios, el siguiente paso es transformarlos para que sean adecuados para el análisis y, especialmente, para los algoritmos de Machine Learning.

¿Por qué es necesario?

  • Diferentes Escalas: Muchos algoritmos (como regresión, SVM, redes neuronales) son sensibles a la escala de las variables. Una variable que va de 0 a 100,000 (ej. salario) podría dominar a una que va de 0 a 100 (ej. edad), llevando a un rendimiento pobre del modelo.
  • Datos Categóricos: Los modelos matemáticos no entienden texto como "Rojo" o "Azul". Necesitamos convertir estas categorías en números.
  • Distribuciones Sesgadas: Algunas variables pueden tener distribuciones muy sesgadas. Transformarlas (ej. con logaritmos) puede ayudar a que los modelos funcionen mejor.
  • Nuevas Perspectivas: A veces, combinar o transformar variables existentes puede crear nuevas características (features) que son más informativas para un modelo.
Para muchas de estas tareas, usaremos Scikit-learn, la librería principal de Machine Learning en Python, que se integra perfectamente con Pandas.
📏

Escalado: Normalización y Estandarización

Existen dos técnicas comunes para escalar variables numéricas:

1. Normalización (Min-Max Scaling): Escala los datos a un rango fijo, generalmente [0, 1].

  • Fórmula: (x - min(x)) / (max(x) - min(x))

2. Estandarización (Standard Scaling): Transforma los datos para que tengan una media de 0 y una desviación estándar de 1.

  • Fórmula: (x - media(x)) / std_dev(x)

Usaremos scikit-learn para esto. ¡Asegúrate de tenerlo instalado! (pip install scikit-learn)

import pandas as pd
from sklearn.preprocessing import MinMaxScaler, StandardScaler

data = {'Edad': [25, 30, 35, 40, 45], 'Salario': [50000, 60000, 75000, 90000, 120000]}
df = pd.DataFrame(data)

# Normalización (Min-Max)
scaler_minmax = MinMaxScaler()
df_normalizado = scaler_minmax.fit_transform(df)
print("Datos Normalizados (Min-Max):\n", df_normalizado, "\n")

# Estandarización
scaler_std = StandardScaler()
df_estandarizado = scaler_std.fit_transform(df)
print("Datos Estandarizados:\n", df_estandarizado)

Salida esperada (los escaladores devuelven arrays de NumPy):

Datos Normalizados (Min-Max):
[[0.    0.   ]
 [0.25  0.142]
 [0.5   0.357]
 [0.75  0.571]
 [1.    1.   ]] 

Datos Estandarizados:
[[-1.414 -1.144]
 [-0.707 -0.763]
 [ 0.    -0.191]
 [ 0.707  0.381]
 [ 1.414  1.717]]
Usa Estandarización si tu algoritmo asume que los datos siguen una distribución normal (gaussiana). Usa Normalización para algoritmos que no hacen esta suposición, como K-Nearest Neighbors (KNN), o en redes neuronales.

Codificación de Variables Categóricas

Los modelos necesitan números, no texto. Aquí hay dos formas comunes de convertir categorías en números:

1. One-Hot Encoding: Crea nuevas columnas binarias (0/1) para cada categoría. Es la técnica más común para variables nominales (sin orden inherente, como "País").

import pandas as pd
df_cat = pd.DataFrame({'Ciudad': ['CDMX', 'Bogota', 'Lima', 'CDMX']})

# La forma más fácil con Pandas es pd.get_dummies()
df_one_hot = pd.get_dummies(df_cat, columns=['Ciudad'])
print("One-Hot Encoding:\n", df_one_hot)

Salida esperada:

One-Hot Encoding: Ciudad_Bogota Ciudad_CDMX Ciudad_Lima 0 0 1 0 1 1 0 0 2 0 0 1 3 0 1 0

2. Label Encoding: Asigna un entero único a cada categoría. Útil para variables ordinales (con un orden claro, como "Bajo", "Medio", "Alto").

from sklearn.preprocessing import LabelEncoder
df_ord = pd.DataFrame({'Nivel': ['Bajo', 'Medio', 'Alto', 'Bajo']})

encoder = LabelEncoder()
df_ord['Nivel_encoded'] = encoder.fit_transform(df_ord['Nivel'])
print("\nLabel Encoding:\n", df_ord)

Salida esperada (el mapeo puede variar):

Label Encoding: Nivel Nivel_encoded 0 Bajo 0 1 Medio 2 2 Alto 0 3 Bajo 1
¡Cuidado! Usar Label Encoding en variables nominales puede confundir al modelo, ya que introduce una relación ordinal artificial (ej. "Lima" (2) > "Bogota" (0)).

Ingeniería de Características (Feature Engineering)

La Ingeniería de Características es el proceso de usar el conocimiento del dominio para crear nuevas variables (features) a partir de los datos existentes. A menudo, estas nuevas variables pueden mejorar significativamente el rendimiento del modelo.

Ejemplo 1: Combinar variables

import pandas as pd
df_propiedades = pd.DataFrame({
    'Precio': [200000, 300000, 250000],
    'Area_m2': [100, 120, 80]
})
# Crear una nueva característica: Precio por metro cuadrado
df_propiedades['Precio_por_m2'] = df_propiedades['Precio'] / df_propiedades['Area_m2']
print(df_propiedades)

Ejemplo 2: Extraer información de fechas

df_fechas = pd.DataFrame({'Fecha_Compra': ['2023-01-15', '2023-05-20', '2023-11-01']})
df_fechas['Fecha_Compra'] = pd.to_datetime(df_fechas['Fecha_Compra'])

# Extraer el mes y el día de la semana
df_fechas['Mes'] = df_fechas['Fecha_Compra'].dt.month
df_fechas['Dia_Semana'] = df_fechas['Fecha_Compra'].dt.dayofweek # Lunes=0, Domingo=6
print("\n",df_fechas)

La ingeniería de características es tanto un arte como una ciencia, y es donde la creatividad y el conocimiento del problema brillan.

Otras Transformaciones

A veces, la distribución de tus datos numéricos no es ideal. Por ejemplo, puede estar muy sesgada. Las transformaciones matemáticas pueden ayudar.

Transformación Logarítmica:

Es útil para reducir el sesgo hacia la derecha en los datos y disminuir el impacto de los outliers. Se suele usar np.log1p(), que calcula log(1+x), para manejar de forma segura los valores de 0.

import numpy as np
df_log = pd.DataFrame({'Ingresos': [1000, 2000, 5000, 100000]}) # Outlier
df_log['Ingresos_Log'] = np.log1p(df_log['Ingresos'])
print("Transformación Logarítmica:\n", df_log.round(2))

Salida esperada:

Transformación Logarítmica:
   Ingresos  Ingresos_Log
0      1000          6.91
1      2000          7.60
2      5000          8.52
3    100000         11.51

Transformaciones Polinómicas:

Consiste en crear nuevas características que son potencias o interacciones de las características existentes (ej. x², y², x*y). Puede ayudar a modelos lineales a capturar relaciones no lineales. Se usa PolynomialFeatures de Scikit-learn.

from sklearn.preprocessing import PolynomialFeatures
# ... código para aplicar PolynomialFeatures ...
