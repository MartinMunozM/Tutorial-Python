¿Qué es la Correlación?

La correlación es una medida estadística que expresa hasta qué punto dos variables están relacionadas linealmente (es decir, cambian juntas a una tasa constante). Es una herramienta fundamental en el EDA para descubrir relaciones entre variables numéricas.

El coeficiente de correlación (generalmente el de Pearson, que es el que usa Pandas por defecto) varía entre -1 y +1:

  • +1: Correlación positiva perfecta. Si una variable aumenta, la otra también aumenta de forma perfectamente proporcional.
  • 0: No hay correlación lineal. Las variables no tienen una relación lineal aparente.
  • -1: Correlación negativa perfecta. Si una variable aumenta, la otra disminuye de forma perfectamente proporcional.

Ejemplos del mundo real:

  • Positiva: La altura y el peso de una persona suelen tener una correlación positiva.
  • Negativa: El tiempo de estudio y el número de errores en un examen suelen tener una correlación negativa.
  • Cercana a cero: El número de calzado y el CI (coeficiente intelectual) probablemente tengan una correlación cercana a cero.
¡Correlación no implica causalidad! El hecho de que dos variables estén correlacionadas no significa que una cause la otra. Puede haber una tercera variable (variable de confusión) que influya en ambas.

Cálculo de Correlaciones: .corr()

Pandas hace que sea muy fácil calcular la matriz de correlación de las columnas numéricas de un DataFrame usando el método .corr().

El resultado es un nuevo DataFrame (la matriz de correlación) donde el índice y las columnas son los nombres de las columnas numéricas originales, y los valores son los coeficientes de correlación entre ellas.

import pandas as pd

data = {
    'Edad': [25, 30, 45, 50, 60],
    'Ingresos_Anuales': [50000, 65000, 90000, 110000, 130000],
    'Horas_Estudio_Semana': [10, 8, 5, 3, 2],
    'Numero_Hijos': [0, 1, 2, 2, 3]
}
df = pd.DataFrame(data)

# Calcular la matriz de correlación
matriz_corr = df.corr()
print("Matriz de Correlación:\n", matriz_corr)

Salida esperada:

Matriz de Correlación:
                         Edad  Ingresos_Anuales  Horas_Estudio_Semana  Numero_Hijos
Edad                  1.000000          0.990262             -0.982708      0.963428
Ingresos_Anuales      0.990262          1.000000             -0.994273      0.928383
Horas_Estudio_Semana -0.982708         -0.994273              1.000000     -0.898863
Numero_Hijos          0.963428          0.928383             -0.898863      1.000000
Interpretación:
  • La diagonal siempre es 1.0 (una variable está perfectamente correlacionada consigo misma).
  • Observa la correlación entre 'Edad' e 'Ingresos_Anuales' (0.99): es una correlación positiva muy fuerte.
  • Observa la correlación entre 'Ingresos_Anuales' y 'Horas_Estudio_Semana' (-0.99): es una correlación negativa muy fuerte.

Por defecto, se usa el método de Pearson. Puedes cambiarlo con df.corr(method='spearman') o 'kendall' para correlaciones no lineales.

Visualización: Mapas de Calor

Una matriz de correlación puede ser difícil de leer si tienes muchas variables. Una forma excelente de visualizarla es con un mapa de calor (heatmap), usando la librería Seaborn.

Un mapa de calor representa los valores de una matriz como colores, lo que facilita la identificación rápida de patrones y relaciones fuertes.

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Usaremos la matriz de correlación del paso anterior
matriz_corr = df.corr()

# Crear el mapa de calor
plt.figure(figsize=(8, 6)) # Opcional: ajustar tamaño
sns.heatmap(
    matriz_corr, 
    annot=True,      # Muestra los valores numéricos en las celdas
    cmap='coolwarm', # Paleta de colores (rojo para +, azul para -)
    fmt=".2f"        # Formato a dos decimales
)
plt.title('Mapa de Calor de Correlaciones')
plt.show()

¿Qué veríamos?

Un gráfico cuadrado donde los colores intensos (ej. rojo oscuro o azul oscuro) indican correlaciones fuertes (positivas o negativas, respectivamente), y los colores cercanos al centro (ej. blanco o gris claro) indican correlaciones débiles o nulas. Esto te permite identificar visualmente las relaciones más importantes de un vistazo.

Aunque no podemos generar el gráfico aquí, este es uno de los pasos más comunes y visualmente impactantes en un EDA. ¡Asegúrate de probarlo en un entorno de Python!

Resumen: Análisis de Correlaciones

Entender la correlación es clave para la selección de características y la comprensión de tu modelo.

🤝 Correlación
Mide la relación lineal entre dos variables (-1 a +1).
🧮 df.corr()
Calcula la matriz de correlación de Pearson por defecto.
🔥 Mapa de Calor
Visualiza la matriz de correlación con seaborn.heatmap().
🎯 Identificación
Permite encontrar variables fuertemente relacionadas (positiva o negativamente).
⚠️ No Causalidad
Recuerda siempre: correlación no implica causalidad.

El análisis de correlaciones te ayuda a entender las interacciones en tus datos y es un paso previo importante para la construcción de modelos de machine learning.
