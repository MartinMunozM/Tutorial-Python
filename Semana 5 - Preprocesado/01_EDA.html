¿Qué es el EDA?

El Análisis Exploratorio de Datos (EDA) es el proceso de investigar conjuntos de datos para resumir sus principales características, a menudo con métodos visuales. Es como ser un detective que busca pistas en los datos antes de construir un caso (o un modelo).

El objetivo del EDA es:

  • Entender la estructura del conjunto de datos.
  • Identificar valores atípicos (outliers) y anomalías.
  • Descubrir patrones, relaciones y tendencias entre variables.
  • Verificar suposiciones que se necesitarán para análisis más avanzados.

Es un paso crucial y fundamental en cualquier proyecto de ciencia de datos.

Para este tutorial, usaremos Pandas para el análisis y mencionaremos librerías como Matplotlib y Seaborn para la visualización, que son el siguiente paso lógico. 
import pandas as pd
import numpy as np

# Crearemos un DataFrame de ejemplo sobre ventas de propiedades
data = {
    'Zona': ['Norte', 'Sur', 'Norte', 'Centro', 'Sur', 'Norte', 'Sur'],
    'Habitaciones': [3, 4, 3, 5, 2, 3, 4],
    'Precio_Miles': [2500, 3200, 2600, 4500, 2100, np.nan, 2900],
    'Antiguedad_Anios': [10, 2, 12, 1, 20, 8, 5]

df = pd.DataFrame(data)
print("DataFrame de ejemplo:\n", df)

Primer Vistazo: .info() y .describe()

Los primeros pasos en cualquier EDA son usar .info() y .describe() para obtener un resumen rápido del DataFrame.

.info(): Nos da información sobre la estructura.

  • El número total de filas (Entries).
  • El número de columnas.
  • El tipo de dato (Dtype) de cada columna.
  • El número de valores no nulos por columna (¡clave para detectar datos faltantes!).
  • El uso de memoria.
# Usaremos el df del paso anterior
print("--- df.info() ---")
df.info()

.describe(): Nos da un resumen estadístico de las columnas numéricas.

  • count: Número de valores no nulos.
  • mean: Media (promedio).
  • std: Desviación estándar (medida de dispersión).
  • min, 25%, 50% (mediana), 75%, max: Resumen de la distribución.
print("\n--- df.describe() ---")
print(df.describe())

Análisis de Frecuencias: .value_counts()

Para las columnas categóricas (como 'Zona'), es útil saber cuántas veces aparece cada categoría. El método .value_counts() es perfecto para esto.

Devuelve una Serie con el conteo de cada valor único, ordenada de mayor a menor.

import pandas as pd
# Usando el df del paso 1
df = pd.DataFrame({'Zona': ['Norte', 'Sur', 'Norte', 'Centro', 'Sur', 'Norte', 'Sur'], 'Habitaciones': [3,4,3,5,2,3,4]})

# Conteo de valores en la columna 'Zona'
conteo_zona = df['Zona'].value_counts()
print("Conteo de propiedades por Zona:\n", conteo_zona, "\n")

# También podemos ver la frecuencia relativa (porcentaje)
frecuencia_zona = df['Zona'].value_counts(normalize=True)
print("Frecuencia de propiedades por Zona (%):\n", frecuencia_zona)

# Se puede aplicar a columnas numéricas también
print("\nConteo por número de habitaciones:\n", df['Habitaciones'].value_counts())

Visualizando Distribuciones y Outliers

Una imagen vale más que mil palabras, y en EDA, las visualizaciones son clave. Aquí mencionamos los gráficos más comunes para entender variables numéricas. Para graficar, se suelen usar librerías como Matplotlib y Seaborn.

Histograma 📊: Muestra la frecuencia de valores en intervalos (bins). Es ideal para ver la forma de la distribución de una variable.

import seaborn as sns
import matplotlib.pyplot as plt

# Este código generaría un histograma del precio
sns.histplot(data=df, x='Precio_Miles', kde=True)
plt.title('Distribución de Precios')
plt.show()

¿Qué veríamos? Un gráfico de barras que muestra cuántas propiedades caen en diferentes rangos de precios. La línea suave (kde=True) es un gráfico de densidad, que suaviza el histograma.

Boxplot (Diagrama de Caja) ▭: Es excelente para resumir la distribución y detectar valores atípicos (outliers).

# Este código generaría un boxplot
sns.boxplot(data=df, x='Precio_Miles')
plt.title('Boxplot de Precios')
plt.show()

¿Qué veríamos? Una "caja" que representa el rango intercuartílico (del 25% al 75% de los datos), una línea en la mediana (50%), y "bigotes" que se extienden para cubrir la mayor parte de los datos. Los puntos individuales más allá de los bigotes son posibles outliers.

# Comparando precios por zona
sns.boxplot(data=df, x='Zona', y='Precio_Miles')
plt.title('Precios por Zona')
plt.show()

Esta versión es aún más útil, ya que nos permite comparar la distribución de precios entre las diferentes zonas.

Aunque no podemos generar gráficos aquí, es fundamental que practiques la creación de estos gráficos en un entorno de Python como Jupyter Notebook o Google Colab para desarrollar tu intuición sobre los datos.

Resumen: Análisis Exploratorio de Datos (EDA)

El EDA es el primer paso para entender tus datos a fondo.

🕵️ Objetivo del EDA
Entender, resumir y visualizar datos para encontrar patrones y anomalías.
🔬 .info() / .describe()
Resumen estructural y estadístico rápido.
#️⃣ .value_counts()
Análisis de frecuencia para variables categóricas.
📊 Histograma
Visualiza la distribución de una variable numérica.
〰️ Gráfico de Densidad (KDE)
Versión suavizada del histograma.
▭ Boxplot
Resume la distribución y detecta outliers.

Estas técnicas te proporcionan una base sólida antes de proceder con la limpieza avanzada y el modelado.
